
# Project Stories

## User Stories

1. As a store owner or staff member,  
   I want to log in securely,  
   so that I can access only the features allowed for my role.

2. As a store owner or staff member,  
   I want to record stock received from suppliers,  
   so that the system can accurately track inventory increases.

3. As a store owner or staff member,  
   I want to record a sale with multiple products,  
   so that inventory is automatically reduced and the transaction is saved correctly.

4. As a store owner,  
   I want to view current stock levels and low-stock products,  
   so that I know which items may need to be restocked.

5. As a store owner,  
   I want to review daily sales and stock movement history,  
   so that I can understand store activity and trace inventory changes.

## MVP Non-Goals

The following are intentionally outside the MVP scope:

- Full accounting, tax reporting, and bookkeeping features.
- An e-commerce storefront or online ordering system.
- Automated GCash or Maya payment processing.
- Barcode scanner or barcode hardware integration.
- Multi-branch inventory management.
- Real-time updates using WebSockets.
- AI-based demand forecasting.
- Microservices or infrastructure such as Kafka, Kubernetes, or Redis.
